## About the Project
This project is part of my Open Source Software course. In this project, I have done an audit of Git, which is a popular open-source version control system.

I studied how Git was created, why it is important, and how it is used in real-world development. I also explored its license, features, and its role in the open-source community.

Along with the theory part, I have also created 5 shell scripts using Linux commands. These scripts helped me understand how automation works in Linux and how open-source tools can be used practically.

## Files in this Project

script1.sh → Shows system information like user, kernel, uptime  
script2.sh → Checks whether Git is installed or not  
script3.sh → Displays disk usage and directory permissions  
script4.sh → Reads log file and counts errors  
script5.sh → Creates a simple open-source manifesto  

---

## How to Run the Project

Open terminal and go to project folder:

cd oss-audit

Give permission to scripts:

chmod +x *.sh

Run scripts one by one:

./script1.sh  
./script2.sh  
./script3.sh  
./script4.sh /var/log/syslog  
./script5.sh
